# Basistha Frontend & Interactive SVG Kundali Engine

**Basistha (वसिष्ठ)** is a modern, responsive Vedic Astrology Web Dashboard and interactive SVG Kundali rendering engine built with **Next.js 14+ (React & TypeScript)** and **Tailwind CSS**, fully branded as **Basistha**.

---

## 🌟 मुख्य कम्पोनेन्टहरू (Core Components)

1. **अन्तरक्रियात्मक SVG कुण्डली इन्जिन (`NorthIndianChart.tsx`):**
   * परम्परागत उत्तर भारतीय हिरा आकार (Diamond Chart) को शुद्ध ज्यामितीय SVG।
   * १२ भाव, ९ ग्रहहरूको स्थान, राशि अङ्कहरू, वक्री `(व)` र अस्त चिन्हहरू।
   * **इन्टरएक्टिभ टूलटिप:** कुनै पनि ग्रहमा माउस लैजाँदा (Hover गर्दा) तत्कालै राशि, अंश, कला, नक्षत्र, पाद, गति र अस्त स्थिति देखिने।
2. **दक्षिण भारतीय कुण्डली (`SouthIndianChart.tsx`):**
   * स्थिर राशीय (Fixed Sign 4x4 Grid) दक्षिण भारतीय कुण्डली ढाँचा।
3. **जन्म विवरण इनपुट फारम (`KundaliForm.tsx`):**
   * वर्ष, महिना, गते/दिन, समय (घण्टा, मिनेट, सेकेन्ड)।
   * नेपालका प्रमुख सहरहरू (काठमाडौँ, पोखरा, ललितपुर, विराटनगर, आदि) र विश्वका सहरहरूको अटो-कम्पलिट ड्रपडाउन।
   * अयनांश छनोट: लाहिडी (Chitrapaksha), रमण, कृष्णमूर्ति (KP), सायन।
4. **दैनिक पञ्चाङ्ग ड्यासबोर्ड (`PanchangaCard.tsx`):**
   * सूर्योदय, सूर्यास्त, दिनमान, ५ अङ्ग (तिथि, वार, नक्षत्र, योग, करण), चौघडिया/बारवेला र अभिजित मुहूर्त।
5. **दशा तालिका (`DashaTable.tsx`):**
   * विंशोत्तरी र योगिनी महादशा/अन्तर्दशाको समय-सीमा सहितको एकर्डियन वृक्ष।
6. **ग्रह स्पष्ट तालिका (`PlanetaryTable.tsx`):**
   * ९ ग्रह र लग्नको डिग्री, मिनेट, सेकेन्ड, नक्षत्र, पाद, गति र मार्गी/वक्री स्थिति।
7. **प्रिन्ट / PDF रेडी मोड:**
   * एक क्लिकमा बिना कुनै सफ्टवेयर ब्राउजरबाटै आकर्षक जन्मकुण्डली प्रिन्ट वा PDF सेभ गर्न सकिने।

## 🚀 चलाउने तरिका (Quickstart)

```bash
cd basistha-frontend

# १. डिपेन्डेन्सी इन्स्टल गर्ने
npm install

# २. लोकल डेभलपमेन्ट सर्भर सुरु गर्ने
npm run dev
```

* **लोकल वेबसाइट ठेगाना:** `http://localhost:3000`
