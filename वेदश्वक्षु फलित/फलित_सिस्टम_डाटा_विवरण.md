## ४. फलित सिष्टमको प्रयोग तथा खोजी विधि

Microsoft 365 Access मा [`Phalit.accdb`](file:///c:/Users/Hp%20Victus/Documents/aiclass/skyvision/वेदश्वक्षु%20फलित/Phalit.accdb) वा [`bibaran1.accdb`](file:///c:/Users/Hp%20Victus/Documents/aiclass/skyvision/वेदश्वक्षु%20फलित/bibaran1.accdb) खोलेर तपाईंले कुनै पनि कुण्डलीको फल सिधै क्वेरी (Query) गरेर निकाल्न सक्नुहुन्छ:

* **कुनै भावमा कुनै ग्रहको फल हेर्न (उदाहरण: प्रथम भावमा सूर्यको फल):**
  ```sql
  SELECT Slock FROM MansagariBhavastaGraha WHERE Bhav = 1 AND Graha = 1;
  ```
* **कुनै भावेशको फल हेर्न (उदाहरण: लग्नेश दशम भावमा बस्दाको फल):**
  ```sql
  SELECT Slock FROM ParasharBhabesh WHERE bhavesh = 1 AND bhav = 10;
  ```
* **विंशोत्तरी दशा-अन्तर्दशा फल हेर्न (उदाहरण: गुरु महादशामा शनि अन्तर्दशा):**
  ```sql
  SELECT Slock FROM ParasharSlock WHERE Mdasha = 5 AND Adasha = 6;
  ```
